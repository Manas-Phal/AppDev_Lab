# 🧭 Productivity Tracker App

## 📱 Overview
A responsive productivity tracker built using *Flutter, designed for both **Web* and *Android* platforms. It helps users stay organized, track daily progress, and stay motivated with real-time quotes and news.

## ⚙ Tech Stack
- *Frontend:* Flutter (Dart)
- *Backend:* Firebase Firestore & Authentication  
- *APIs:* NewsAPI, QuotesAPI, Gemini API (Chatbot)  
- *Database:* SQLite (for offline history)  
- *Testing:* Flutter Test  

## 💡 Features
- 🔐 *Role-Based Access:* Guest, User, VIP, Admin (Student/Professor)  
- 📊 *Dashboard & Analytics:* Visual progress tracking with charts  
- ✅ *Task Management:* Add, edit, delete, and mark tasks complete  
- 🕒 *History Screen:* View past actions and API usage  
- 🤖 *AI Chatbot:* Gemini-powered conversational assistant  
- 🌗 *Enhanced UI/UX:* Modern layout, smooth animations, and dark mode  
- ☁ *Firebase Sync:* Secure login and real-time data updates  

## 🧪 Testing
Tested using *Flutter Test* and manual validation for API calls, role permissions, and responsive UI layouts.
